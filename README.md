# KORUS Toolkit

Browser-extension project for `https://knue.korus.ac.kr/`.

Product stack is decided in `docs/design/chrome-extension-stack.md`: Chromium (Chrome and Edge),
Manifest V3, Vite, TypeScript, pnpm. Run `pnpm install`, then `pnpm build` to create the unpacked
extension in `dist/`. See `backlog.md` for the next work item and `docs/` for repository constraints.
